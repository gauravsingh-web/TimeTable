🎓 Design & Analysis of Algorithms (ADA) Theory

Graph Vertex Coloring & Recursive Backtracking Explained

1. Problem Formulation as Graph Vertex Coloring

University Timetabling is a known NP-Complete Constraint Satisfaction Problem (CSP). We translate this real-world problem into graph theory:

  • Vertices \(V\): Every individual lecture session during the week (e.g. 4 lectures of ADA for CSE-A = 4 distinct vertices).
  • Edges \(E\) (Mutual Exclusion): An undirected edge \((u, v)\) is drawn if two lectures CANNOT occur at the same time:
    • Batch Conflict: Lecture \(u\) and \(v\) belong to the same student cohort (e.g., CSE-A students cannot attend two classes at once).
    • Teacher Conflict: Lecture \(u\) and \(v\) share the same faculty (e.g., Dr. Juhi Jain cannot teach CSE-A and CSE-B simultaneously).
  • Colors \(K\): Discrete weekly timeslots (5 days \(\times\) 8 periods = 40 available timeslots).

2. The Recursive Backtracking State-Space Tree

The C++ engine (algorithm.cpp) uses Depth-First Search (DFS) with backtracking:

bool solve(int vertexIndex) {
    if (vertexIndex == totalVertices) return true; // Base Case: All colored!
    
    int v = vertexOrder[vertexIndex];
    for (int color = 0; color < TOTAL_TIMESLOTS; color++) {
        for (int room = 0; room < TOTAL_ROOMS; room++) {
            if (isSafe(v, color, room)) {
                assignedSlot[v] = color;  // Make Choice
                assignedRoom[v] = room;
                
                if (solve(vertexIndex + 1)) return true; // Recurse
                
                assignedSlot[v] = -1;     // Backtrack (Undo Choice)
                assignedRoom[v] = -1;
            }
        }
    }
    return false;
}

3. Welsh-Powell Degree Ordering Heuristic

Standard backtracking can suffer from worst-case exponential time \(O(K^V)\). To guarantee sub-millisecond execution, we order vertices by descending degree (number of conflicts). Lectures with overlapping teachers (like Dr. Juhi Jain or Dr. Ahmad Zaman Khan) are scheduled first. This "Most Constrained Variable" heuristic prunes invalid subtrees near the root!
